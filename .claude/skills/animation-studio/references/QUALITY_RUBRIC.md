# Quality rubric (evaluate as pass / fail, not vague praise)

1. Script fidelity: all essential nouns/actions/claims represented; no changed meaning.
2. Style fidelity: geometry, edge treatment, shading, materials, motion and camera ALL fit the chosen visual language, not a mere palette swap.
3. Strong establishing shot: viewer recognizes central subject/topic immediately, with deliberate framing and contrast.
4. Scene-specific visual storytelling: each beat visually advances information or action. No looping, generic filler.
5. Consistency: same people/props/colors across scenes unless transformation is scripted.
6. Visual legibility: no severe crop, overlap, poor contrast or blown highlights; safe margins for portrait UI.
7. Motion: meaningful follow-through and pacing; not stilted; not chaotic unless story demands it.
8. Audio truth: user audio untouched except intentional mix; duration aligned; no invented audio/voice; captions as requested.
9. Source/editability: deterministic original source and storyboard saved for repeat edits.
10. Export proof: actual H.264 MP4 and verified metadata, not just preview stills or promises.

If any criterion fails, fix it before calling the output complete. If unable, disclose precisely which failed and why.
