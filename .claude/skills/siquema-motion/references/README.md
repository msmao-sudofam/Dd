# Every reel M Mo likes, broken down

One file per reference reel: `NN-<short-name>.md`. Break each one down into moves
and rules, not adjectives. Any move worth stealing goes into `moves.json` as `new`.

Template:

```
# NN · <name>
source:   <link or file in brand/assets/past-reels/>
added:    YYYY-MM-DD
why M Mo likes it: <one line, in their words if possible>

## breakdown
**<Move name>**: <what literally happens on screen, timing, density>
...

## rules taken
- ...

## moves added → moves.json
- <id>
```
