# Amazon Sourcing SOP — Warehouse Runner + SellerAmp

Goal: buy at Costco / warehouse clubs and resell on **Amazon** — only items you're
**allowed to sell**, that **profit**, and that **move fast**.

> Key rule: **Amazon does not accept Costco receipts to ungate.** So if SellerAmp shows you're
> gated on an item, you **cannot** fix it with Costco sourcing → skip it. Only buy the green ones.

---

## Tools
- **Warehouse Runner** — finds the markdown (`.97/.00/.88`), tracks price across your warehouses.
- **SellerAmp SAS** — per-**your-account** eligibility + profit + velocity check. ($19.95–$49.95/mo)

## The per-item gate (scan every candidate through SellerAmp)

| Check | Pass condition | If fail |
|---|---|---|
| **Eligibility** | ✅ green / "YES" | Gated → **SKIP** (Costco can't ungate you) |
| **Hazmat / Dangerous Goods** | no flag | Flag → skip (unless you do hazmat) |
| **IP / brand alert** | clear | Alert → skip |
| **ROI** | **≥ 30%** (green thumb, after Amazon fees) | Below → skip |
| **Net profit / unit** | **≥ $4–5** | Below → skip |
| **Est. sales / month + BSR trend** | high & stable (not "sells once/month") | Slow → skip |
| **Competing offers / Buy Box** | few sellers, Amazon not in Buy Box | Crowded → skip |

**Buy only if every row passes.** Start with **8–10 test units**, reorder winners.

## The loop
1. Warehouse Runner alert fires on a markdown, OR you spot a `.97/.00/.88` tag in-store.
2. Scan the item into **SellerAmp**.
3. Run the gate table above.
4. All green → buy test batch. Use Warehouse Runner to find the same markdown across your
   other tracked warehouses to scale the buy.
5. List on Amazon, monitor sell-through, reorder what moves.

## Why category lists don't matter here
With SellerAmp checking **your** account per ASIN, you don't pre-filter by category — the tool
tells you item by item. Toys & Games is just statistically the *easiest* ungated category, so
you'll see more greens there, but any aisle can produce a green.

## Reminders
- Eligibility is **account-specific** — no external list can tell you what YOU can sell; only
  SellerAmp against your account can.
- Re-check periodically: brands enter Amazon Brand Registry and gate over time.
- Keep a running list of your confirmed-green ASINs so repeat trips are fast.
