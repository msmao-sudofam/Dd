# Implementation reference lock

The user-approved BRIEF.md is the build target. Refero research on October 30, 2026 retrieved the full Andercore and Exo Ape styles.

| Decision | Source | Rule | Application |
| --- | --- | --- | --- |
| Near-black flat canvas and hairline seams | Andercore + brief | No elevation; 0px cards, 4px buttons | All public and CRM surfaces |
| Large tight Archivo display type over architecture | Exo Ape + brief | Borrow scale/composition only | Storefront hero; large section titles |
| Amber accent | Brief | Logo, primary buttons and active states only | No amber decorative surfaces |
| Real job media | Brief | Visible facts only | Classified manifest and static gallery |
| Stage columns and lead drawer | Refero Aboard/Marathon/Attio screen search | Stage hierarchy; details separate from board | Phone-first CRM with wrapping columns and modal drawer |
| Hero assembly | Handoff | Specified dimensions, stages and camera path | Code-native Three.js geometry |

Reject: shadows, soft cards, decorative gradients, fabricated evidence, stock imagery, palette averaging. Media uses actual company photos; no generated project imagery. Visual QA must check desktop and phone hero stages against these rules.
